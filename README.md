# Village Fashion - iOS/iPadOS Game

A delightful iOS and iPadOS game where adorable tiny creatures visit stores in their village to buy fashionable clothes and accessories!

## Features

### Adorable Creatures
- 8 different creature types: Bunny, Cat, Fox, Bear, Panda, Koala, Hamster, and Mouse
- Each creature has their own name, personality, and coin purse
- Fully customizable with various fashion items

### Shopping System
- **4 Unique Stores** in the village:
  - 🎩 **Fancy Hats** - Specializing in headwear
  - 👔 **Chic Boutique** - Offering stylish tops and dresses
  - 👟 **Sole Mates** - The best shoes in town
  - 💎 **Sparkle & Shine** - Accessories galore

### Fashion Items
- Multiple categories: Hats, Tops, Bottoms, Shoes, and Accessories
- Each item has a unique emoji representation
- Items have different prices based on their rarity
- Purchase items using coins earned in-game

### Wardrobe System
- Manage your creature's fashion collection
- Equip and unequip items in real-time
- See your creature instantly change appearance
- Mix and match different items for unique looks

### Game Mechanics
- **Coin Economy**: Each creature starts with coins to spend
- **Shopping**: Visit stores to browse and purchase items
- **Customization**: Equip items from your wardrobe
- **Collection**: Build a complete fashion collection

## Technical Details

### Built With
- **SwiftUI** - Modern declarative UI framework
- **Swift Observation** - For reactive state management
- **iOS 17+** - Latest iOS features
- **iPad Support** - Optimized for both iPhone and iPad

### Architecture
- **Models.swift** - Data models for creatures, items, stores, and wardrobe
- **GameState.swift** - Observable game state management
- **VillageView.swift** - Main village interface with store cards
- **StoreView.swift** - Shopping interface for each store
- **CreatureView.swift** - Creature rendering and wardrobe management
- **ContentView.swift** - Main app navigation and layout

### Key Features
- Clean, modular SwiftUI architecture
- Responsive grid layouts
- Smooth animations and transitions
- Intuitive touch interfaces
- Beautiful color schemes per store

## How to Play

1. **Select Your Creature** - Choose from your collection of adorable creatures
2. **Visit the Village** - Browse the four unique stores
3. **Shop for Fashion** - Buy items using your creature's coins
4. **Customize Your Look** - Open the wardrobe to equip items
5. **Mix and Match** - Create unique fashion combinations

## Getting Started

### Requirements
- Xcode 15.0 or later
- iOS 17.0+ or iPadOS 17.0+
- Swift 5.9+

### Building the Project
1. Open `VillageFashion.xcodeproj` in Xcode
2. Select your target device (iPhone or iPad)
3. Press `Cmd+R` to build and run
